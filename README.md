# GestionSouscription

Application de gestion de liste de souscripteurs développée avec Qt (C++).

## Fonctionnalités

- Ajouter, modifier et supprimer des entrées
- Recherche en temps réel
- Tri croissant / décroissant
- Pagination (20 entrées par page)
- Persistance des données via fichier CSV
- Un fichier `bdd.csv` est généré pendant l'éxécution
